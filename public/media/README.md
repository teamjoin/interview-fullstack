# Médias de démonstration

Trois photographies de produits fictifs ont été créées avec l’outil intégré `imagegen` en mode génération de nouvelles images, sans image de référence. Les MP4 sont des animations de ces images réalisées avec FFmpeg : léger zoom centré et fondus, sans audio. Ils ne représentent pas une génération vidéo effectuée par RenderLab.

Chaque clip dure 8 secondes : 720 × 1280, 24 images/seconde, H.264, pixels yuv420p et faststart. Les JPEG associés servent d’affiches. Les fichiers sont servis localement ; aucune clé d’API ni connexion à un fournisseur de médias n’est nécessaire.
